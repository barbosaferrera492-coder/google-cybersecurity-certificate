# Google Cybersecurity Certificate

Repositório de anotações, resumos e laboratórios práticos do programa 
Google Cybersecurity Certificate (Coursera).

## Sobre o programa
Certificação profissional em cibersegurança composta por 8 cursos, 
cobrindo fundamentos de segurança, redes, Linux, SQL, detecção de 
ameaças e resposta a incidentes.
